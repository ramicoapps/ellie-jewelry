# Ellie Jewelry – אתר החנות

## איך עורכים מוצרים ומחירים
כל המוצרים נמצאים בקובץ אחד: `assets/js/products.js`.
- **מחיר:** משנים את המספר ליד `price`. כרגע כל המחירים **זמניים**.
- **מחיר לפני הנחה:** מוסיפים `oldPrice: 450,`.
- **תגית:** `badge: "חדש",` או `badge: "רב מכר",`.
- **"האהובים שלנו" בדף הבית:** `featured: true,`.
- **מספר וואטסאפ:** בשורה `WHATSAPP_NUMBER` בראש הקובץ.

## הוספת מוצר חדש
1. שמים את התמונה בתיקייה `images/`.
2. מוסיפים את שם הקובץ ושם באנגלית לרשימה ב-`scripts/prepare_images.py`, ומריצים:
   `python scripts/prepare_images.py "C:/web ellie jewelry"`
   (או פשוט מעתיקים תמונה בפורמט webp לתיקייה `assets/img/products/`).
3. מעתיקים מוצר קיים ב-`products.js` ומעדכנים אותו.

תמונות על רקע לבן מקבלות אוטומטית את רקע השמנת של האתר.

## העלאה לאוויר (בחינם)
גוררים את כל התיקייה (בלי `images/` ו-`scripts/`) לאתר https://app.netlify.com/drop, ומקבלים כתובת. אפשר לחבר אחר כך דומיין משלך.
